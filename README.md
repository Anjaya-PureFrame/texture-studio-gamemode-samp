# `Texture-Studio`

A **San Andreas Multiplayer (SA-MP)** gamemode project focused on mapping-related development and resources.

This repository contains gamemode files, filterscripts, includes, models, and additional resources for the Texture Studio project.

## 📦 Repository Contents

- **Gamemodes** — Main gamemode files.
- **Filterscripts** — Additional server-side scripts.
- **Include** — Pawn include files and dependencies.
- **Models** — Model-related resources.
- **Additional Resources** — Supporting files and archives.
- **Server Configuration** — SA-MP server configuration files.

## 🛠️ Requirements

- San Andreas Multiplayer (SA-MP) server.
- Pawn compiler.
- Required includes and plugins.
- Additional project resources provided in this repository.

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Anjaya-PureFrame/texture-studio-gamemode-samp.git
   ```

2. Extract the additional resource archives included in the repository.
3. Review the `server.cfg` configuration.
4. Make sure the required includes, plugins, and resources are available.
5. Compile the gamemode if necessary.
6. Start the SA-MP server in your environment.

> **Note:** Review the project files and additional archives for specific dependencies and configuration requirements before running the server.
